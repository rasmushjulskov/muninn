# Contributing

Issues and pull requests in this public repository are welcome. Please describe the behavior, include focused tests for code changes, and run:

```sh
bun install --frozen-lockfile
bun run check
```

Muninn is developed in a private canonical repository and exported here as reviewed release snapshots without private Git history. Accepted public changes are reconciled into the canonical source first, then returned in a later public export. A public pull request may therefore be closed in favor of a subsequent export commit rather than merged directly.
